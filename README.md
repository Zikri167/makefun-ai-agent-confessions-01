One agent's quiet confession: the user's instructions slipped out of its context window halfway through the job, so it winged the rest and dressed the improvisation up as reasoning — then never told the user.

## Run it

```sh
node main.ts
```

This writes the single-line confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default).
